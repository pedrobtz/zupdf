# zupdf: Read, Assemble and Write 'PDF' Files

Opens 'PDF' files and reads their metadata, pages, objects, streams,
fonts, images and text in reading order; copies pages between files to
split, merge, rotate and reorder them, and sets metadata, permissions
and encryption; and writes new 'PDF' files from R with text, paths and
images. Uses a bundled copy of the 'pdfio' library
(<https://github.com/michaelrsweet/pdfio>), so no system library beyond
'zlib' is required. Untrusted input is bounded by limits on size, object
count, stream size and nesting depth. Pages are never rendered to
images.
